# Color Palette Options for Flashcard Learning App

## Option 1: **Ocean Blue & Teal** (Recommended for Focus & Calm)

**Perfect for:** Extended study sessions, reduced eye strain, professional feel

```css
--primary: #3b82f6; /* Vibrant blue - buttons, accents */
--primary-hover: #2563eb; /* Darker blue on hover */
--secondary: #06b6d4; /* Teal - highlights, success states */
--background: #0f172a; /* Deep slate blue - main background */
--surface: #1e293b; /* Card backgrounds, elevated surfaces */
--surface-hover: #334155; /* Hover states */
--text-primary: #f8fafc; /* Almost white - main text */
--text-secondary: #94a3b8; /* Muted blue-gray - secondary text */
--border: #334155; /* Subtle borders */
--success: #10b981; /* Green for correct answers */
--error: #ef4444; /* Red for errors */
```

**Why this works:**

- Blue promotes focus and concentration (research-backed)
- Teal adds freshness without being distracting
- Excellent contrast ratios (WCAG AAA compliant)
- Modern, trustworthy aesthetic
- Easy on the eyes for long sessions

## Implementation Notes

### Accessibility

All palettes meet WCAG AA standards (minimum) and most meet AAA:

- Text contrast ratios: 7:1+ (primary), 4.5:1+ (secondary)
- Interactive elements: 3:1+ contrast
- Focus indicators clearly visible

### Usage Guidelines

- **Primary color**: Buttons, active states, important CTAs
- **Secondary color**: Highlights, badges, progress indicators
- **Background**: Main app background
- **Surface**: Cards, modals, elevated content
- **Text colors**: Hierarchical information display

### Recommendation

**Option 1 (Ocean Blue & Teal)** is recommended because:

1. Research shows blue improves focus and productivity
2. Professional yet approachable
3. Works well for all age groups
4. Excellent for extended study sessions
5. Modern without being trendy
